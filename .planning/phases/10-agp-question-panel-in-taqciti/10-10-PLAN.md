**1. O que muda (em linguagem comum)**
Escrevemos o roteiro de testes que uma pessoa vai seguir no Chrome de verdade, com uma reunião de verdade: 12
testes, cada um com o passo a passo ("abra isto, clique naquilo, espere tantos segundos") e o que deve acontecer.
Depois rodamos todos os testes automáticos da fase de uma vez e montamos a versão da Taqciti que aponta para o
backend no seu computador, para a pessoa só precisar recarregar a extensão.

**2. Como vai ser alterado**
- Task 1 (tracer, commit `docs(10-10)`): reescrever `10-UAT.md` (mecânico de documentação; nenhum código).
- Task 2 (sem commit de código; resultado no SUMMARY): portão automático + `npm --prefix taqciti run build` com as
  duas variáveis (o `taqciti/dist` é ignorado pelo git).

**3. Riscos de cada ação**
- Task 1: (a) passo a passo vago ("teste a pausa") que uma pessoa não técnica não consegue seguir; (b) prometer
  comportamento que o código não tem (como o antigo "fixada some no TTL"); (c) roteiro que manda mexer em `.env`;
  (d) teste da WR-05 impossível de reproduzir à mão; (e) usar dados reais de cliente no Supabase de produção.
- Task 2: (a) o build sem as variáveis apontar para o endereço padrão (já aconteceu, Armadilha 6); (b) a suíte ter
  falha intermitente e o portão "passar" sem rodar; (c) a fumaça não subir no Windows por causa de `python3`.

**4. Como prevenir**
- Task 1: (a) cada teste com passos numerados e o que olhar na tela; (b) conferir cada "esperado" contra o código
  dos planos 10-01..10-09 e contra o CONTEXT (D-09 corrigido); (c) prohibition deste plano; crédito e chave do
  Gemini são ação humana; (d) o teste 8 usa o "Network throttling" do DevTools do service worker para segurar o
  encerramento (procedimento assistido, marcado como tal) e registra que a recusa é silenciosa (D-18); (e) só
  clientes `ZZ-TESTE-<assunto> <data>`, apagados por id no fim (regra do `TESTES-MANUAIS-POS-FASE-10.md`).
- Task 2: (a) as duas variáveis na mesma linha do comando e conferência do endereço no build; (b) `fails_when`
  com "failed" e contagem; (c) `AGP_PYTHON=python`.

**5. Como consertar (plano de rollback)**
- Task 1: `git revert <sha docs(10-10)>` devolve o UAT de 7 testes.
- Task 2: build errado → refazer o mesmo comando com as variáveis e dar ↻ em `chrome://extensions`; nada versionado
  muda.

**6. Decisões que são do usuário/time**
- Já tomadas: D-13 (prova com IA real), D-15 (testes novos e build com as variáveis), D-18 (recusa silenciosa),
  D-19 (sem backend falso estendido). Nenhuma DECISÃO EM ABERTO.

## Plano em 7 seções (obrigatório — CLAUDE.md §"Regras de Planejamento de Tasks")

**1. O que muda (em linguagem comum)**
A página do web app que hoje diz "baixe a extensão (zip)" passa a dizer "instale a Taqciti". É como trocar a placa
de uma loja que mudou de endereço: a porta (o menu "Extensão Chrome" e o endereço `/extension`) continua a mesma, mas
o que está escrito e para onde o botão leva mudam. A página também avisa: "se você tem a extensão antiga, remova antes".
Não ensina a configurar endereço de servidor nem chave — a Taqciti já vem pronta (D-07, D-08).

**2. Como vai ser alterado**
- Task 1 (decisão do time): qual link a página usa (GitHub Release, pasta do Drive ou os dois) e a URL exata.
- Task 2 (tracer, UM commit `feat(09-04)` — muda comportamento da UI): criar `frontend/src/lib/taqcitiInstall.ts` e o
  teste; criar `frontend/src/components/extension/StepList.tsx`; reescrever `frontend/src/pages/ExtensionPage.tsx`;
  remover a constante antiga de `frontend/src/lib/labels.ts` (único consumidor era a página). Ordem: teste (RED) → dados
  (GREEN) → componente → página → `labels.ts`.
- Task 3 (humano): abrir a página no navegador e clicar no link.
Nada no backend muda.

**3. Riscos de cada ação**
- Task 1: link inventado ou de repositório não oficial (phishing por link); link para um arquivo com versão no nome
  (quebra a cada release).
- Task 2: botão continuar apontando para o zip antigo; texto prometer chave/URL de backend; quebrar a rota
  `/extension`; página passar do limite de tamanho; apagar a constante antiga e outro arquivo ainda usá-la (build quebra).
- Task 3: o visual (A2 do 09-RESEARCH) ficar estranho; link abrir a página errada.

**4. Como prevenir**
- Task 1: a URL vem só do time; precisa ser `https` e apontar para a página de releases (`.../releases/latest`), não
  para um arquivo.
- Task 2: o teste `taqcitiInstall.test.ts` trava https + host/repositório confirmados, ausência do zip antigo e de
  chave/URL, presença do aviso e dos 3 sistemas; grep negativo no `frontend/src`; `npm --prefix frontend run build`
  (tsc pega import quebrado); `awk` limita a página a 120 linhas; rota e `navItems.ts` não são tocados.
- Task 3: checkpoint de navegador com passos concretos.

**5. Como consertar (plano de rollback)**
- Task 2: `git revert <sha-feat(09-04)>` — a página antiga e a constante voltam juntas (um commit só).
- Task 1/3: link errado → novo commit trocando só o valor de `TAQCITI_RELEASES_URL` e o host esperado no teste.

**6. Decisões que são do usuário/time**
- **DECISÃO EM ABERTO (Task 1):** URL do repositório original da Taqciti e da release; usar GitHub, Drive ou os dois.
  O executor PARA até a resposta.
- Já decidido (não reabrir): rótulos "Extensão Chrome" dos formulários ficam (decisão 7); bloco "ID da sessão +
  copiar" fica (decisão 9).
- Critério do Claude (registrado): o rótulo do menu (`navItems.ts`) e o banner da `HomePage` continuam como estão —
  "Extensão Chrome" segue verdadeiro (a Taqciti é uma extensão do Chrome, mesma lógica da decisão 7) e D-06 manda
  manter o item de menu; o caminho manual "carregar sem compactação" não entra na página (o guia do instalador já
  cobre e evita parecer a página antiga).

**7. Verificação (ponta a ponta)**
- `npm --prefix frontend test` (semente real: `taqcitiInstall.test.ts`), `npm --prefix frontend run lint`,
  `npm --prefix frontend run build`.
- Navegador: `npm --prefix frontend run dev`, abrir `http://127.0.0.1:5173/extension`, clicar no link (Task 3).

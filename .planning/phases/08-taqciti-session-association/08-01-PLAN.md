**1. O que muda (em linguagem comum)**
Hoje a Taqciti manda a fala para "o ID que está salvo na configuração", qualquer que seja a reunião — é como
um carteiro que entrega toda carta no mesmo endereço fixo. Depois deste plano, cada reunião ganha a sua
própria "etiqueta de destino" (a associação), guardada no navegador. Enquanto a etiqueta não diz "este
cliente, esta sessão", nada sai — a reunião fica só guardada na Taqciti (modelo B, D-04). A etiqueta nasce
"pendente" quando a reunião é detectada com o envio ligado; se a reunião acabar sem ninguém escolher o
cliente, a etiqueta passa a "não enviada" (para o fim da reunião perguntar depois, D-09). Se o navegador ou
o service worker reiniciar no meio de uma escolha, a etiqueta nunca fica presa num estado intermediário.
Ninguém vê tela nova ainda — as telas vêm nos planos de UI; aqui é o "motor" que garante que nada é enviado
por palpite.

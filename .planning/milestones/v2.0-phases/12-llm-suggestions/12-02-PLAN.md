## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo.get_project_llm_config → Supabase projects | pricing_api_key_secret_id sai do banco; nunca logado |
| repo.decrypt_pricing_api_key → vault.decrypted_secrets | api_key plaintext em memória apenas durante o request; não logada nem incluída em respostas de erro |
| service → LLM provider | api_key vai pela rede até o provider via HTTPS |
| LLM response → banco | Saída estruturada do LLM inserida via bulk_insert_features; horas validadas como Decimal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
